Podporované databázy a systémy

Bezpečné čítanie dát priamo z lokálnych databáz bez rizika poškodenia existujúcej evidencie.

MRP DOS / Staršie verzie

Priama extrakcia hlavičiek a položiek faktúr z lokálnych `.dbf` tabuliek. Nevyžaduje žiadne úpravy pôvodného softvéru.

  • Metóda: Read-only DBF parser
  • Výstup: ISDOC / ePostak XML
  • Režim: Automatický daemon / plánovač

MRP Vizuálny systém

Konektor pre vizuálne verzie MRP. Extrahujeme vystavené faktúry v reálnom čase priamo zo štruktúry databázy.

  • Metóda: Databázový konektor / DBF
  • Výstup: ISDOC / ePostak XML
  • Režim: Automatické spracovanie

Softip (Legacy verzie)

Riešenie pre staršie generácie systému Softip. Zabezpečuje bezpečný odchyt fakturačných dát bez nutnosti upgrade-u modulu.

  • Metóda: Dátový bridge
  • Výstup: Štruktúrované XML
  • Režim: Beží na pozadí Windows/Linux

KROS VEMA

Extrakcia fakturačných a účtovných podkladov pre firmy využívajúce systémy VEMA bez podpory moderného API konektora.

  • Metóda: Priame čítanie dátových súborov
  • Výstup: ISDOC XML
  • Režim: Dávkové / okamžité generovanie

Vyvíjané dBase / Visual FoxPro (.dbf)

Univerzálny konektor pre akékoľvek interné aplikácie postavené na databázových súboroch DBF.

  • Metóda: Custom DBF schéma mapping
  • Výstup: ePostak / Custom XML
  • Režim: Plne prispôsobené na mieru

Špeciálny interný / Vlastný softvér

Ak máte vnútrofiremný systém vyvinutý na mieru bez dokumentácie, mapujeme databázové tabuľky a napojíme export priamo.

  • Metóda: Reverzná analýza schéma DB
  • Výstup: Validné XML
  • Režim: Zákazkový vývoj konektora

Ako prebieha nasadenie

Od prvej analýzy po plne funkčné automatické generovanie XML do 10 dní.

Krok 01

Analýza databázy

Preveríme štruktúru vašej databázy (DBF/SQL) a overíme prítomnosť všetkých povinných polí pre e-faktúru.

Krok 02

Vývoj konektora

Pripravíme skript namapovaný presne na vaše fakturačné polia a nastavíme validáciu XML štruktúry.

Krok 03

Testovacia prevádzka

Nasadíme skript do testovacieho režimu a overíme správnosť vygenerovaných XML dokumentov.

Krok 04

Ostré spustenie

Aktivujeme automatické generovanie na pozadí. Váš systém posiela e-faktúry bez akéhokoľvek manuálneho zásahu.
