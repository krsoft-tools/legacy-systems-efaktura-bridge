Automatizácia na pozadí

Sledovanie zmien v reálnom čase a konverzia do XML prebiehajú automaticky bez potreby ručných exportov alebo opätovného zadávania dát.

Podporované databázy a systémy

Bezpečný priamy odpočet iba na čítanie z lokálnych databáz bez rizika poškodenia údajov.

MRP DOS / Staršie verzie

Priamy odpočet hlavičiek a položiek faktúr z lokálnych `.dbf` súborov bez úpravy pôvodného softvéru.

  • Metóda: DBF parser (iba na čítanie)
  • Výstup: ISDOC / UBL / Vlastné XML
  • Spustenie: Služba na pozadí / Plánovač

Vizuálny systém MRP

Konektor navrhnutý pre vizuálne verzie MRP. Odpočet vystavených faktúr v reálnom čase priamo z databázového úložiska.

  • Metóda: Databázový konektor / DBF
  • Výstup: Validované XML
  • Spustenie: Automatický proces riadený udalosťami

Softip (Staršie systémy)

Riešenie namieru pre staršie verzie Softip. Bezpečne zachytáva fakturačné údaje bez potreby drahých aktualizácií modulov.

  • Metóda: Dátový most (Data Bridge)
  • Výstup: Štruktúrované XML
  • Spustenie: Služba na pozadí pre Windows / Linux

ERP VEMA

Odpočet dát pre firmy využívajúce systém VEMA bez natívneho REST API alebo moderných možností exportu do XML.

  • Metóda: Priame čítanie súborov
  • Výstup: ISDOC XML
  • Spustenie: Dávkové alebo okamžité spracovanie

dBase / Visual FoxPro (.dbf)

Univerzálny konektor pre vlastné desktopové aplikácie vyvinuté na mieru nad DBF súbormi.

  • Metóda: Mapovanie vlastnej DBF schémy
  • Výstup: e-Faktúra / Vlastné XML
  • Spustenie: Plne prispôsobený dátový most

In-House / Vlastné ERP

Pre vlastné informačné systémy bez dokumentácie. Vykonávame spätné inžinierstvo databázových schém na vytvorenie spoľahlivých exportérov.

  • Metóda: Spätné inžinierstvo databázy
  • Výstup: Plne validné XML
  • Spustenie: Vývoj konektora na kľúč

Postup nasadenia

Od úvodnej analýzy databázy až po plne automatizovanú generáciu XML do 10 dní.

Krok 01

Audit databázy

Skontrolujeme vašu DBF/SQL štruktúru a overíme dostupnosť všetkých povinných polí faktúry.

Krok 02

Vývoj konektora

Napíšeme skript na mieru podľa vašej štruktúry a nastavíme prísnu validáciu XML schémy.

Krok 03

Testovacia prevádzka

Integráciu spustíme v testovacom prostredí a overíme platnosť XML voči národným validačným nástrojom.

Krok 04

Ostré nasadenie

Aktivujeme automatizáciu na pozadí. Váš systém odosiela platné e-faktúry bez ručného zásahu.
